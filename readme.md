# Vefforritun 1, 2026: Verkefni 4, Spurningaleikur sýnilausn

Sýnilausn á [verkefni 4](https://github.com/vefforritun/vef1-2026-v4), sjá [verkefnalýsingu](verkefnalysing.md).

Þarf að hafa Node.js og npm uppsett til að keyra þetta verkefni.

```bash
npm install
npm run dev # keyra þróunarumhverfi
npm run build # búa til keyrsluútgáfu í dist/
npm run lint # keyra eslint
```
